# Collec' 23-151

Collection de cartes de la fam's 23-151 (Bordel's), pour le week's fam's.

- `index.html` : l'appli des joueurs (inscription par pseudo et code, boosters, album, classement).
- `admin.html` : la page d'administration (joueurs, cadeaux, cartes, photos, sons, réglages).
- `config.js` : l'adresse de la base Supabase et sa clé publique.
- `assets/` : police Zagot's, logos de rareté, dos de carte, image par défaut des Gadz.

Les cartes, les collections et les médias sont stockés dans Supabase.
Les tirages se font côté serveur : l'appli ne fait qu'afficher le résultat.
